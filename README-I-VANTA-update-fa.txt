I VANTA — بسته به‌روزرسانی

فایل‌ها:
1) I-VANTA-admin-plus.html — نسخه ویرایش‌شده سایت موجود
2) upload-site-ad.ts — Edge Function امن آپلود عکس تبلیغ
3) firestore.rules — قوانین Firestore متناسب با قابلیت‌های افزوده‌شده

مهم: این بسته هنوز به سرویس زنده وصل و end-to-end آزمایش نشده است. قبل از جایگزینی سایت اصلی، یک کپی پشتیبان از فایل فعلی نگه دار.

راه‌اندازی عکس تبلیغ در Supabase:
1) در Storage یک باکت تازه با نام site-ads بساز.
2) باکت site-ads را Public قرار بده؛ فقط عکس‌های تبلیغ داخل آن هستند و قرار است برای بازدیدکنندگان سایت قابل مشاهده باشند.
3) محدودیت فایل را 5MB و MIME typeها را image/jpeg، image/png و image/webp بگذار.
4) در Edge Functions یک تابع با نام دقیق upload-site-ad بساز و محتوای upload-site-ad.ts را در آن قرار بده.
5) گزینه Verify JWT with legacy secret را برای این تابع خاموش کن؛ تابع خودش توکن Firebase را بررسی می‌کند.
6) Secret موجود SERVICE_ROLE_KEY باید در Edge Function Secrets باقی مانده باشد. آن را داخل کد سایت قرار نده.

رسیدهای PLUS:
- باکت plus-receipts باید Private بماند.
- تابع view-plus-receipt که قبلاً ساختی باید فعال باشد.
- گزینه Verify JWT with legacy secret برای آن نیز خاموش باشد، چون تابع توکن Firebase و UID مدیر را خودش بررسی می‌کند.
- تابع مشاهده رسید فقط برای UID مدیر تعریف‌شده در کد مجاز است.

Firestore:
- فایل firestore.rules مجموعه‌های plusRequests، plusMembers، siteConfig، siteAds، challenges، challengeCompletions، challengeLeaderboard، lotteries و lotteryEntries را پوشش می‌دهد.
- اگر در پروژه‌ات مجموعه‌های دیگری هم استفاده می‌شوند، قبل از انتشار باید قوانین فعلی آن‌ها را با این نسخه ادغام کنی؛ جایگزینی کورکورانه ممکن است دسترسی قابلیت‌های دیگر را ببندد.
- بعد از انتشار Rules، تست کن که کاربر عادی نتواند تبلیغ یا قرعه‌کشی بسازد یا حذف کند.

قابلیت‌های اضافه‌شده در HTML:
- مدیریت فهرست تبلیغات، ویرایش، توقف/فعال‌سازی و حذف
- انتخاب محل نمایش تبلیغ: خانه، چالش‌ها یا قرعه‌کشی‌ها
- آپلود تصویر تبلیغ از مسیر Edge Function
- مشاهده امن رسید از داخل پنل ادمین
- حذف کامل سند درخواست PLUS هنگام رد
- حذف چالش
- مدیریت قرعه‌کشی، شرکت کاربر و انتخاب برنده؛ کاربران PLUS دو شانس محاسباتی دارند
- مدیریت و نمایش باکس هفتگی
- صفحه‌های جدا برای چالش‌ها، لیدربرد و قرعه‌کشی‌ها
- آیکون ÀVanta فقط در انتهای اسکرول نمایش داده می‌شود و صفحه aboutvanta را باز می‌کند
- انتخاب زبان اکنون جهت صفحه و بخشی از برچسب‌ها را عوض می‌کند؛ ترجمه کامل تمام متن‌های پویا هنوز نیاز به تکمیل دارد.

اعتبارسنجی انجام‌شده:
- JavaScript فایل HTML با node --check از نظر Syntax بررسی شد.
- اتصال واقعی به Firebase/Supabase، قوانین منتشرشده و رفتار UI در مرورگر هنوز از این محیط قابل آزمایش نبود.
